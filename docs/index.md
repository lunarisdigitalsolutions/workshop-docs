This is the single source of truth for the Pizza Luna ordering platform. Every page lives in the
repository next to the system it describes and is reviewed in the same pull request as the change.

## Find your starting point

Each audience asks one question and owns one area of the documentation.

| Audience | Question | Area |
| --- | --- | --- |
| Customers and branch staff | How do I use it? | [User](user/index.md) |
| Product owners and branch managers | Why does it exist? | [Domain](domain/index.md) |
| Developers | How does it work? | [Development](development/index.md) |
| Architects and tech leads | Why was it built this way? | [Architecture](architecture/index.md) |
| Operations and on-call | What do I do when it breaks? | [Operations](operations/index.md) |

## What belongs here

A page belongs in this repository when the information changes together with the system: decisions,
interfaces, deployment and operating knowledge, domain rules and user guidance. Meeting notes,
project planning and customer-specific material stay in their own tools.

The rules for writing and placing pages are in the
[documentation guideline](development/guidelines/documentation.md).
