Use these terms in code, documentation and conversations. If a term is missing, add it here before
using it elsewhere.

| Term | Meaning |
| --- | --- |
| Branch | One Pizza Luna restaurant with its own kitchen, opening hours and delivery zone. |
| Branch manager | Staff member responsible for a branch's menu availability and opening hours. |
| Delivery zone | The postal codes a branch delivers to. Each postal code belongs to at most one branch. |
| Fulfilment type | How the customer receives an order: `Pickup` or `Delivery`. |
| Kitchen board | The screen in each branch that lists accepted orders in preparation order. |
| Menu item | A pizza, drink or side that can be ordered. The menu is shared across all branches. |
| Availability | Whether a menu item can be ordered in a specific branch right now. |
| Order | A customer's request for one or more menu items from one branch. |
| Order number | Short, human-readable identifier shown to the customer, for example `HB-0427`. |
| Order status | The current lifecycle state of an order; see [Order lifecycle](business-rules/order-lifecycle.md). |
| Topping | An extra ingredient added to a pizza for a surcharge. |
| Tracking link | The link sent to a customer to follow an order without an account. |
